# MoneyWiz Viewer 安装包

这里只存放 MoneyWiz Viewer（MoneyWiz 的 Windows 只读查看器）的安装包，供下载安装和应用内自动更新使用。安装包里没有任何财务数据：数据只能通过 Tailscale 从配对过的 Mac 读取。

到 [Releases](https://github.com/TheRookieGit/moneywiz-windows-release/releases/latest) 下载最新的 `MoneyWiz-Viewer-Setup-x.y.z.exe`。装好后应用会自动检查并安装更新。

> 安装包没有代码签名，第一次运行 Windows 可能提示「已保护你的电脑」，点「更多信息 → 仍要运行」即可。
